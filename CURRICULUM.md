## Estructura de una Página de Contenido

Cada página interactiva sigue esta estructura:

1. **Header** - Navegación + botón volver
2. **Título** - Nombre del tema
3. **Concepto** - Explicación del tema con cajas de colores
4. **Tip del profesor** - Consejo pedagógico
5. **Actividad interactiva** - Demo visual / ejercicio práctico
6. **Quiz** - Preguntas de opción múltiple o interactivas
7. **Videos** - Sección placeholder para links de YouTube

### Colores de Cajas
- **Azul:** Concepto / Información
- **Verde:** Tip / Consejo
- **Naranja:** Advertencia
- **Morado:** Ejemplo destacado

- Builder interactivo (agregar/quitar categorías)

### Ecuaciones (`alg-ecuaciones.html`)

- Ecuaciones de un paso (x + a = b, ax = b)
- Quiz de resolución
