Promedio (Media Aritmética)

El promedio es un número que representa el valor "central" de un conjunto de datos. Se calcula sumando todos los valores y dividiendo por la cantidad de datos.

Fórmula del promedio

$$\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$$

Ejemplo: Notas de una prueba: $5, 6, 7, 4, 5$

$\text{Suma} = 5 + 6 + 7 + 4 + 5 = 27$
$n = 5$
$\bar{x} = \frac{27}{5} = 5{,}4$

¿Cuándo se usa el promedio?

Notas del curso: Para sacar el promedio de las notas del semestre
Temperatura: Para calcular la temperatura promedio del mes
Edades: Para saber la edad promedio de un curso

Consejo

El promedio no siempre es un número entero. Puede tener decimales. En Chile, las notas se redondean generalmente a un decimal.
