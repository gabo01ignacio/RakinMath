📈 ¿Qué es un Pictograma?
Un pictograma usa dibujos o iconos para representar cantidades. Cada icono significa una cantidad fija, y así puedes ver los datos de forma visual y divertida.

💡 ¿Cómo se lee?

Primero mira la clave: te dice cuánto vale cada icono. Por ejemplo, si dice "1 🍎 = 2 personas", significa que cada manzana representa 2 personas. Si ves 3 manzanas, son 3 × 2 = 6 personas.

🎬 Ejemplo: ¿Qué deporte prefieren?
